# WiggleWoo's Word Quest — Voiceover Pickup Round 4 (Comprehension Questions)

**Prepared for:** Content Narrator (same voice/style as the Discovery Room fact narration — not the WiggleWoo character voice)
**Scope:** 80 lines — one combined narration per comprehension question

---

## Context

Every comprehension question currently shows text-only (a question + 2-3 answer choices) with no audio at all — the one place left in the app where a child who can't fully read yet has no way to know what's being asked. This script covers all 80 questions, one combined line each (question + all choices read together, in the same style as a friendly quiz-show host). If a per-choice tap-to-hear version is wanted instead later, that's a separate, larger recording ask — this round is the simpler combined-clip version.

**Voice direction:** Same warm, clear, unhurried delivery as the Discovery Room fact narration. Read each choice as a distinct option with a small pause between them — a child needs to be able to tell where one choice ends and the next begins by ear alone.

**Note:** The `Correct (QA only)` column is for internal reference only — do not read the correct answer differently or hint at it in delivery. Every choice should sound equally plausible.

## Delivery

- **File type:** WAV, 44.1kHz, 16-bit or higher.
- **Naming:** Use the `File name` column exactly — these map 1:1 to each fact's own ID in the code.
- **Trim:** ~100ms head/tail silence.
- **Normalize:** Peak to -1dB, matching the existing fact-narration files.
- **Wording:** A starting point, not locked in — reword for natural flow if a line reads awkwardly aloud. The file name is what matters for wiring it up.
